# Ocean Documentation

This folder owns the current ocean rendering documentation.

## Authority Docs

- `godot_4_6_water_rendering_rules.md` - stable Godot 4.6 renderer facts and
  water-rendering rules. Update this only when a fact is re-checked against a
  newer Godot version, official Godot source, or another primary source.
- `architecture.md` - current Godotwind ocean architecture. Update this every
  time the active ocean, underwater, receiver-waterline, shore, or wetness
  architecture changes.

## Focused Docs

- `../../plans/shore_overhaul.md` - shore mask, shore-wave, and shoreline
  displacement work.
- `../../plans/wetness_system.md` - wetness ownership and implementation plan.

## Historical Docs

Ocean audits and session handoffs under `docs/audit/` and `docs/archive/` are
history. They can explain why a decision happened, but they are not current
authority unless they point back to the two authority docs above.
